# 配置与交互

三种模式共用 `FxConfig`，坐标 / 尺寸 / 边距统一使用 vp。传入新配置时库保存配置快照，修改原对象后需要再次调用 `updateConfig()`。

## 配置默认值

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `position` | `undefined` | 初始绝对坐标，指定后优先于 gravity |
| `gravity` | `FxGravity.TOP_LEFT` | 初始九宫格定位 |
| `offset` | `{ x: 0, y: 0 }` | 初始定位后的偏移 |
| `margin` | 四边为 0 | 非负 vp 安全边距 |
| `displayMode` | `FxDisplayMode.Normal` | 普通、仅点击或仅展示 |
| `adsorb` | `true` | 拖动结束时吸附 |
| `edgeAdsorb` | `FxEdgeAdsorb.LEFT_RIGHT` | 吸附方向 |
| `rebound` | `true` | 拖动结束回位动画开关，需启用配置动画 |
| `halfHide` | `false` | 到配置边缘时部分隐藏 |
| `halfHideRatio` | `0.5` | 隐藏比例，允许 0..0.9 |
| `animation` | `{ enabled: false, durationMs: 300, curve: FxAnimationCurve.EASE }` | 显隐 / 回位等动画配置 |
| `clickIntervalMs` | `300` | 连续点击最小间隔，非负毫秒 |

配置中的坐标、比例和时长必须有限；边距 / 时长 / 点击间隔非负。非法配置抛 `INVALID_CONFIG`。`updateConfig` 接收完整 `FxConfig`，不是部分 patch；想保留之前配置，持有自己的配置对象，或先调用它的 `copy()` 再修改。

## 定位与移动

九宫格可用值：`TOP_LEFT`、`TOP_CENTER`、`TOP_RIGHT`、`CENTER_LEFT`、`CENTER`、`CENTER_RIGHT`、`BOTTOM_LEFT`、`BOTTOM_CENTER`、`BOTTOM_RIGHT`。

初始定位按 `position` 或 `gravity` 选择，再叠加 `offset`，最后限制在合法边界内。`(0, 0)` 是真实坐标，不能表示“未设置”。启用了存储且存在有效历史位置时，恢复位置可覆盖初始定位。

已显示实例调整位置请调用 `move(x, y, animate?)` 或 `moveByVector(dx, dy, animate?)`，默认不动画。坐标相对于对应宿主 / 显示区域，读取 `getX()` / `getY()` 得到逻辑位置。半隐藏时逻辑位置与屏幕上可见部分的左上角可能不同。

`gravity` / `offset` 用于初始定位；更新这两个配置项不会把已有位置重新当作初始位置计算。需要重新按九宫格放置时重建控制器，或直接移动。

运行期宿主 / 显示区域变化时会保留贴边方向及另一轴的相对位置，并限制在新边界内。持久化恢复在内容尺寸 / 边距也变化时有精度边界，详见[位置存储](位置存储.md)。

## 吸附、回弹与半隐藏

方向可用值：`LEFT`、`RIGHT`、`TOP`、`BOTTOM`、`LEFT_RIGHT`、`TOP_BOTTOM`。双边方向选择较近边缘。

`adsorb: false` 不进行吸附；拖动结束仍回到合法边界内。`rebound: false` 关闭回位动画，不能用它开启越界放置。

`halfHide: true` 且浮窗处于 `edgeAdsorb` 对应边缘时，按 `halfHideRatio` 隐藏内容的一部分。比例 0 不隐藏，0.5 隐藏一半，最大 0.9。半隐藏改变可见区域，内容尺寸与存储坐标仍按完整内容计算。

## 修改配置示例

下面函数接收已经创建的控制器；其创建、Builder 和释放见[快速开始](快速开始.md)。

```ts
import { FxControlHandle, FxConfig, FxEdgeAdsorb, FxAnimationCurve } from 'floatingx';

export async function enableHalfHide(control: FxControlHandle): Promise<void> {
  await control.updateConfig(new FxConfig({
    adsorb: true,
    edgeAdsorb: FxEdgeAdsorb.LEFT_RIGHT,
    halfHide: true,
    halfHideRatio: 0.5,
    animation: { enabled: true, durationMs: 300, curve: FxAnimationCurve.EASE }
  }));
}
```

曲线还支持 `LINEAR`、`EASE_IN`、`EASE_OUT`、`EASE_IN_OUT`。需要移动动画时显式传 `true`，并启用配置动画以覆盖系统模式的动画要求。动画可被后续隐藏、移动或取消中断，不要将一次 Promise 成功当作屏幕最终绘制完成通知。

## 显示模式

| 模式 | 拖动 | 库交互回调 / 内容按钮 |
| --- | --- | --- |
| `Normal` | 允许 | 允许 |
| `ClickOnly` | 禁止 | 允许 |
| `DisplayOnly` | 禁止 | 禁止，内容区域透传 |

`DisplayOnly` 禁用整棵内容的交互，内部关闭按钮也不可用，应保留其他业务退出入口。系统模式的跨应用透传、焦点等表现需在目标设备确认。

## 拖动区域与回调

`interactions` 在创建工厂中传入：

- `dragArea?: { x, y, width, height }`：内容内部 vp 矩形，建议限定在标题，宽高为正。
- `onClick?: () => void | Promise<void>`：拖动区域点击。
- `onLongPress?: () => void | Promise<void>`：拖动区域长按。
- `onDrag?: (position: FxPoint) => void | Promise<void>`：拖动中位置回调。

未指定 `dragArea` 时，整个浮窗内容覆盖拖动 / 点击区域，可能拦截内部按钮。带按钮时明确划定标题区，将按钮放在区外。库提供长按回调，没有“必须长按才可拖动”的配置。

事件与交互回调可返回 Promise。同步异常或异步 rejection 只通过 `EVENT_CALLBACK_FAILED` 日志报告，不撤销已成功的浮窗操作。点击 / 长按 / 拖动完整例子见 [ScopeDemo.ets](https://github.com/Petterpx/FloatingX-Harmony/blob/main/entry/src/main/ets/pages/ScopeDemo.ets)。
