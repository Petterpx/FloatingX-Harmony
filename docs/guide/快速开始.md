# 快速开始

## 环境与安装

使用 HarmonyOS Stage 工程、ArkTS / ArkUI 与 API 12 或更高的目标环境。使用与 DevEco Studio 配套的 HarmonyOS SDK；库最低兼容 HarmonyOS 5.0.0（API 12）。

当前尚未发布到 OHPM，安装本地 HAR：

1. 在 DevEco Studio 打开仓库，完成依赖同步。
2. 构建 `floatingx` 模块的 HAR（`assembleHar`），在模块构建产物中取得 `floatingx.har`。
3. 将 HAR 复制到消费模块的 `libs/floatingx.har`。
4. 编辑消费模块的 `oh-package.json5` 并同步依赖：

```json5
{
  "dependencies": {
    "floatingx": "file:./libs/floatingx.har"
  }
}
```

已配置命令行 HarmonyOS 工具链时，在仓库根目录也可运行：

```sh
hvigorw --mode module -p module=floatingx@default -p product=default assembleHar --no-daemon
```

局部和应用内浮窗无需 `ohos.permission.SYSTEM_FLOAT_WINDOW`。HAR 本身不声明该权限。仓库的 `entry` 是包含系统模式的示例应用，消费者应按自己使用的模式配置。

## 完整局部浮窗页面

将下面代码放到应用模块的 `pages/Index.ets`，并在 Stage 页路由配置中注册页面。ArkUI 的 `wrapBuilder` 是全局 API，无需从库导入。

```ts
import { FloatingX, FloatingXHost, FxContent, FxControl, FxConfig } from 'floatingx';

class FloatParams {
  label: string;
  constructor(label: string) { this.label = label; }
}

@Builder
function floatContent(params: FloatParams) {
  Text(params.label)
    .width(180).height(64)
    .backgroundColor('#DDEEFF').borderRadius(12)
}

@Entry
@Component
struct Index {
  @State private message: string = '';
  private active: boolean = false;
  private control: FxControl<FloatParams> = FloatingX.createScope({
    content: new FxContent(wrapBuilder(floatContent),
      new FloatParams('拖动我'), { width: 180, height: 64 }),
    config: new FxConfig({ position: { x: 20, y: 80 } })
  });

  aboutToAppear(): void {
    this.active = true;
    this.run(this.control.show());
  }

  aboutToDisappear(): void {
    this.active = false;
    this.run(this.control.cancel());
  }

  private run(action: Promise<void>): void {
    action.catch((error: Error) => {
      if (this.active) this.message = error.message;
    });
  }

  @Builder
  pageContent() {
    Column({ space: 12 }) {
      Text(this.message)
      Button('显示').onClick(() => this.run(this.control.show()))
      Button('隐藏').onClick(() => this.run(this.control.hide()))
    }.width('100%').height('100%').padding(16)
  }

  build() {
    Stack() {
      FloatingXHost({
        control: this.control,
        host: () => { this.pageContent(); }
      }).width('100%').height('100%')
    }.width('100%').height('100%')
  }
}
```

`FxContent` 的第三个参数是正数 vp 初始尺寸；Builder 使用自己的参数类。不要将 Android View、XML 或 Compose 内容直接传入。根内容使用百分比尺寸时，以这里声明的初始尺寸作为百分比基准。

`FloatingXHost.host` 是底层页面内容。通过 `host: () => { this.pageContent(); }` 传入闭包，可保留页面状态和回调的正确拥有者。

## 第一次使用要记住

- 工厂同步校验参数并返回控制器，工厂错误用 `try/catch`；窗口创建和权限检查发生在首次 `show()`。
- 显示、隐藏、移动、更新与取消都是 Promise 操作，使用 `await` 或 `.catch()`。
- `show()` 成功可表示已接受显示意图；实际显示以 `isShow()` 或 `SHOW` 事件为准。
- `cancel()` 结束当前实例；再次需要浮窗时重新创建。
- 临时移除 `FloatingXHost` 会隐藏浮窗，保留显示意图；业务结束时仍需取消。
