# 位置存储

位置保存默认关闭。在创建工厂时增加 `storage` 即启用；无需额外手动保存。存储在首次实际显示前恢复，拖动结束或程序移动完成后保存。

## 选择存储

| 实现 | 范围 | 适合 |
| --- | --- | --- |
| `FxMemoryStorage` | 同一个对象的内存 | 当前进程内复用位置 |
| `FxPreferencesStorage` | 应用 Preferences | 重启应用后恢复 |
| 实现 `FxStorage` | 自定义 | 自有持久化方式 |

`FxMemoryStorage` 的每个新对象都有独立记录。需要在取消 / 重建后恢复位置时复用同一个对象，不要每次创建新对象。Preferences 默认文件名为 `floatingx_positions_v1`，也可以在构造函数第二个参数指定业务文件名。

## 完整局部存储示例

此函数定义参数类和 Builder，返回局部控制器。调用者将它绑定到 `FloatingXHost`，显示并在业务结束时取消；宿主完整代码见[快速开始](快速开始.md)。

```ts
import common from '@ohos.app.ability.common';
import { FloatingX, FxContent, FxControl, FxConfig, FxPreferencesStorage } from 'floatingx';

class StoredParams {
  label: string;
  constructor(label: string) { this.label = label; }
}

@Builder
function storedContent(params: StoredParams) {
  Text(params.label).width(180).height(64).backgroundColor('#DAF5DD')
}

export function createStoredFloat(context: common.Context): FxControl<StoredParams> {
  return FloatingX.createScope({
    content: new FxContent(wrapBuilder(storedContent),
      new StoredParams('位置会保存'), { width: 180, height: 64 }),
    config: new FxConfig(),
    storage: {
      namespace: 'player', key: 'mini-player',
      storage: new FxPreferencesStorage(context)
    }
  });
}
```

应用内多实例完整例子见 [MultipleDemo.ets](https://github.com/Petterpx/FloatingX-Harmony/blob/main/entry/src/main/ets/pages/MultipleDemo.ets)，包含 Context 获取、Preferences、白名单与卸载。

## 键与隔离

- scope：传 `namespace`、业务 `key` 与 `storage`。
- app / system：仅传 `namespace` 与 `storage`，业务键由安装时的作用范围和 tag 生成。
- `namespace` / `key` 必须非空。命名保持稳定才能恢复同一个浮窗。
- system 显式降级成 app 后仍使用安装时的 system 键，不会与相同业务的 app 键混用。

库生成实际存储键；不要依赖其编码格式或自行拼接内部键。想共享位置，请由业务实现明确的 `FxStorage` 策略。

## 恢复与清除

记录包含版本、完整逻辑位置、宿主尺寸与贴边方向。宿主尺寸变更时按相对位置和边缘恢复，并限制在合法边界。现有记录不保存历史内容尺寸 / 安全区 / 边距；这些也变化时不能精确还原旧比例。

首次显示前有显式程序移动时，以业务新位置为准，避免迟到恢复覆盖。无记录、无效记录或存储失败不会阻止浮窗显示；失败通过 `STORAGE_FAILED` 事件 / 日志报告。

`await control.clearPosition()` 清除当前实例对应的历史位置，不移动当前浮窗。后续拖动 / 移动仍可保存新的记录。若需要重新回到默认初始位置，清除后取消并重建实例。

## 自定义存储协议

```ts
import { FxPositionRecord } from 'floatingx';

export interface PositionStore {
  load(key: string): Promise<FxPositionRecord | undefined>;
  save(key: string, value: FxPositionRecord): Promise<void>;
  clear(key: string): Promise<void>;
}
```

上述形状与导出的 `FxStorage` 一致：实现类写作 `implements FxStorage`，无记录返回 `undefined`，失败拒绝 Promise。记录的 `version` 当前为 1；`position` 与 `viewport` 使用 vp，`edge` 使用 `FxEdge`。实现应复制值并等待写入完成，不能保存共享可变引用。

源码：[FxStorage.ts](https://github.com/Petterpx/FloatingX-Harmony/blob/main/floatingx/src/main/ets/storage/FxStorage.ts) · [FxPreferencesStorage.ets](https://github.com/Petterpx/FloatingX-Harmony/blob/main/floatingx/src/main/ets/storage/FxPreferencesStorage.ets)。
